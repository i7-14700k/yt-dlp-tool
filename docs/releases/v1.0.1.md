Adds support for Epidemic Sound music links such as
`https://www.epidemicsound.com/music/tracks/<UUID>/` in Download and Inspect.
The bundled extractor resolves the site's MP3 playback URLs and prefers the
full mix over individual stems. Choose Original to keep the MP3, or WAV,
AAC or MP3 to convert it.

Local integration tests cover the real download queue, plugin loading,
MP3 downloads and WAV conversion using a local media server. Live Epidemic
Sound verification remains pending because the development environment's
network proxy rejects connections to the site.

Windows downloads:

- `Ingest-1.0.1-Setup-x64.exe`: per-user installer.
- `Ingest-1.0.1-portable-x64.zip`: unzip and run `Ingest.exe`.
- `SHA256SUMS.txt`: checksums for both downloads.

The Windows build is unsigned, so SmartScreen may display a warning.
